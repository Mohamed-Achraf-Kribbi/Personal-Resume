# CV Personnel Interactif

Ce projet est un CV personnel interactif développé dans le cadre du module **Programmation Web 2** (Licence L2).

## 🚀 Technologies Utilisées

- **HTML5 & CSS3** : Pour la structure sémantique et la mise en forme (Premium Design, Dark Mode, Glassmorphism).
- **jQuery** : Pour l'interactivité du DOM.
  - Animation des barres de compétences au défilement.
  - Accordéon pour la section Formation.
  - Validation du formulaire de contact.
- **ReactJS** : Pour la création de composants d'interface dynamique.
  - `<SocialLinks />` : Rendu des liens sociaux.
  - `<ProjectList />` & `<ProjectCard />` : Affichage de la liste des projets et des détails individuels.

## 📁 Structure du Projet

- `index.html` : Fichier principal contenant la structure de la page.
- `styles.css` : Feuille de style personnalisée.
- `script.js` : Scripts jQuery gérant les animations et la validation.
- `components.jsx` : Composants React pour les sections dynamiques.

## 🌐 Déploiement

Le site est déployé via GitHub Pages et est accessible à l'adresse suivante :
[https://mohamedachraf.github.io](https://mohamedachraf.github.io)

## 💡 Remarques

Le projet utilise les CDN pour intégrer React, Babel et jQuery sans nécessiter d'étape de compilation complexe (Node.js/NPM), garantissant ainsi une compatibilité et une simplicité d'exécution directes dans n'importe quel navigateur moderne.
